# Sales Report Generator

A Python automation project that reads sales data from CSV files and generates professional Excel reports.

## Features

- Read CSV files
- Generate Excel reports
- Auto-fit columns
- Freeze panes
- Excel Table
- Sales summary
- Charts
- Dashboard

## Technologies

- Python
- openpyxl
- CSV

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```
